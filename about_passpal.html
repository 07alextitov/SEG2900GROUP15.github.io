About PassPal

The offline, desktop-first password manager built for students, builders, and privacy-maximalists.

See Features View Pricing

Our Mission

We created PassPal to keep credentials under your control — no always-on cloud, no surprise subscriptions, and no dark-pattern lock-ins. Your vault lives with you, encrypted locally, with optional manual export for backup.

🔐 Security Principles

  • Local-first, offline-capable vault
  • Strong encryption with a single master key you control
  • No tracking, telemetry, or analytics by default
  • Simple file backups you can verify yourself

🖥️ Browser-Free Access

Optimized for keyboard workflows and quick search — copy, paste, rotate, done. No browser extension required.

📦 Transparent by Design

Clear pricing, readable export formats, and human-sized UI. What you see is what you own.

How PassPal Works

  1. Create a master password (only you know it).
  2. Store logins, API keys, and notes in your local vault.
  3. Use quick search and one-click copy to fill credentials anywhere.
  4. Back up on your terms: external drive, encrypted archive, or both.

Roadmap

  • Import from popular managers
  • Optional 2-device sync via user-owned storage
  • Per-entry sharing for teams and clubs
  • CLI companion for power users
